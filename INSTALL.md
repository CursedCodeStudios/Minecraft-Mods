# Installing the suite

Use Minecraft Java 26.2 with Java 25, Fabric Loader 0.19.5 or newer, and Fabric API 0.161.0+26.2 or a compatible newer release. The release manifest records exact requirements for this build.

Extract the suite ZIP, then copy the desired JARs from its `mods` directory into your Minecraft instance's `mods` directory. Replace older versions of the same mods; do not keep both installed. The JSON manifest is informational and need not be installed. The suite contains Fry Utilities, Bedrock Scout, and Seed Scout. All are client-only and independently installable; no server installation is needed. Fry Utilities now contains Slime Scout, Monument Scout, and End City Scout; remove their old standalone JARs when upgrading.

The three scouts inside Fry Utilities and the separate Bedrock Scout optionally integrate with Xaero's Minimap (compiled against 26.5.1 for Minecraft 26.2). Add a compatible Xaero's World Map for full-map display, along with any dependencies those mods require. Xaero mods and Fabric API are not included in this ZIP.

The four waypoint scouts share the **Minecraft Scouts** waypoint set in each dimension. After replacing the JARs and restarting Minecraft, recorded markers are created as permanent Xaero waypoints in this shared set as you visit their dimensions. They are saved in Xaero and reused on reconnect, and remain available after leaving the dimension. Select it in Xaero's waypoint menu. Old per-mod sets may remain empty; existing user waypoints and sets are preserved. Each scout's marker toggle affects only its own markers.

Slime Scout starts automatically, creates one waypoint per recorded chunk, and adds a `[visits: N]` counter. Use `/slimescout` for status and commands. Existing Slime Scout saves remain compatible.

Monument Scout creates one waypoint per recognizable ocean monument: gray while surveying, aqua when sponges remain, yellow when no sponges remain, and green when no sponges and zero elders are observed. No recorded kills are required. Stay near the monument center with surrounding chunks loaded to survey zero elders. On multiplayer this reflects client-reported entities, not an authoritative server query. Use /monumentscout for commands; select the shared Minecraft Scouts waypoint set.
Monument progress is permanent: sponge-cleared markers can only advance to OK, and OK markers never revert, including after restarts.
Slime Scout remembers deleted waypoint chunks and filters recognized slime split children. Use /slimescout restore in a dismissed chunk only if you explicitly want its waypoint back. Deletions made before 1.2.2 must be repeated once because earlier versions did not save them.

End City Scout recognizes End city entrances and ships, inspects each ship's elytra item frame, and counts living shulkers observed by the client. Use `/endcityscout here` for results and ship-room coordinates; select the shared Minecraft Scouts waypoint set. Names use `End City (Elytra) (6 Shulkers)` with a blue `EC-E6` symbol, or `End City (6 Shulkers)` with a yellow `EC-6` symbol without observed elytra. Unknown counts use `?`. These compact labels retain the latest saved observations; ship status is never included. Visit the ship's display spot for five seconds to establish missing elytra. Large or partially loaded cities may remain unknown rather than falsely claiming zero shulkers. Ship searches cover 192 blocks on each horizontal axis from the recorded entrance; results do not certify arbitrary large cities empty.

Bedrock Scout scans loaded Nether-ceiling chunks from Y=123 through Y=127 for horizontal 3x3 bedrock squares with no bedrock beneath any of the nine blocks in the ceiling band. It records the lowest valid height at each center and creates a permanent purple `B3` waypoint named `Nether Roof 3x3 (Y=height)`. Use `/bedrockscout` for status, `/bedrockscout here` for the nearest result, and `/bedrockscout scan` to rescan loaded chunks. Inspect and test a candidate safely before spawning a wither.

Seed Scout recovers modern Java world seeds locally from vanilla Nether bedrock. Stand in the Nether with the current chunk and its four cardinal neighbors loaded, then run `/seedscout crack` or `/seedscout crack <threads>`. It reads Y=4 and Y=123, runs in the background, and prints the full signed seed as clickable chat text. Old pre-1.18 terrain, customized generation, affected old Paper terrain, or edited bedrock may not produce a result. The JAR embeds the LGPL Nether Bedrock Cracker 1.5.0 engine and its license texts; no separate dependency is needed.

Fry Utilities fully replaces Villager Trading Plus and Nautilus Scout and contains the former standalone Slime Scout, Monument Scout, and End City Scout. Click a trade to perform it from inventory, hold Shift to repeat it, or hold Ctrl for vanilla behavior. Middle-click a trade row to star it for book labels. Shift-middle-click a starred row to mark it for villager highlighting; the marker is green when available and red when sold out. Villagers glow green only when a trade is both starred, marked, and available. Living drowned holding a nautilus shell glow coral orange; those holding a trident glow teal. Trade choices are saved per villager and server/world; an open villager screen confirms stock state. Remove all five superseded standalone JARs before installing `fry-utilities-<suite-version>.jar`.

Mod Menu is optional. If installed, its Fry Utilities configuration screen controls the four highlights and the villager display range.
